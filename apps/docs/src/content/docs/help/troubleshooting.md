title: Troubleshooting
description: Resolve command, connection, and Ask problems, or report a bug.
---

## Command not found

Install the launcher under Settings → Command line, then open a new terminal.
Run `whiteboard --version`. If it still fails, follow
[Enable the command](/agents/#enable-the-command).

## My agent cannot find Whiteboard tools

Keep Whiteboard open and repeat your
[agent's setup steps](/agents/#connect-from-whiteboard). Reload the agent's
tools or restart it, as its guide instructs. Run the
[connection test](/agents/#test-the-connection) before creating a review.

## Ask cannot find my agent

Make sure that the agent's command-line interface (CLI) runs in a new terminal.
Restart Whiteboard to detect it. For supported agents and sign-in requirements,
see [Ask inside Whiteboard](/agents/#ask-inside-whiteboard).

## Report a problem

Use Report a bug in the app or open a
[GitHub issue](https://github.com/devdotfast/whiteboard/issues). Include the app
version, agent version, operating system, steps to reproduce, and exact error.
Read the selected attachments before sending. See
[Privacy and data](/help/privacy/#user-initiated-bug-reports) for their
contents, or ask on [Discord](https://discord.gg/wYvd2cpMQg).
