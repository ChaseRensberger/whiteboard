Whiteboard is a canvas for thoughtful software. The
agent creates a review with explanations, diagrams, and links to source code.
You can inspect the changes and ask the agent questions about them.

## Get started

Install Whiteboard and connect your coding agent. Then open the agent in a local
Git repository and ask it to create a review. The guides below cover each step.

## Supported agents

Whiteboard connects to Claude Code, Codex, Cursor, OpenCode v2, Pi, oh-my-pi,
and GitHub Copilot CLI. Setup uses an agent plugin or MCP, a protocol that
connects agents to tools.

[Connect your agent](/agents/) lists the setup method for each agent and its
support for Ask Agent, Whiteboard's question panel.

## Review and give feedback

Read the explanation and open its source links to inspect the code. To request a
revision, [send feedback to your agent](/guides/give-feedback/). For questions
about selected text, use [Ask Agent](/guides/ask-agent/).

After you change the source code, ask the agent to update the review.

## About these docs

These guides describe
[Whiteboard v0.2.0](https://github.com/devdotfast/whiteboard/releases/tag/v0.2.0),
the stable release as of October 4, 2026. Ask Agent is a preview feature.
Support varies by agent version and operating system.

Whiteboard stores local reviews on your machine. Read
[Privacy and data](/help/privacy/) for details about data storage, telemetry,
and sharing. For help, see [Troubleshooting](/help/troubleshooting/) or join
[Discord](https://discord.gg/wYvd2cpMQg).
