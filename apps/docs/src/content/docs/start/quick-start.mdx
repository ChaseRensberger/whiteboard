---
title: Quick Start
description: Install Whiteboard, connect your agent, and open a review.
---

Use a coding agent that is installed and signed in.

## 1. Open Whiteboard

[Download Whiteboard](https://dev.fast/install/) for your operating system.
Install and open the app.

## 2. Connect your agent

If prompted, select Install whiteboard in PATH.

On the welcome screen, select your agent under Connect your agents. Copy the
setup prompt into your agent and follow its instructions.

For manual setup, see [Connect your agent](/agents/).

## 3. Create a review

Open your agent in a local repository with branch changes. If your base branch
is not `main`, replace it in this prompt:

```text
Review my current branch against up-to-date main and open the result in Whiteboard.
```

Without a branch ready, select Take the tour on the welcome screen. For other
review types and next steps, see [Create a review](/guides/create-a-review/).
